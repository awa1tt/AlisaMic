## 📌 Что делает программа?

`AlisaMic` превращает вашу Яндекс Станцию в **высококачественный беспроводной микрофон** для компьютера:

1. **Использует встроенный микрофонный массив колонки**: звук захватывается микрофонами Станции, проходит через штатные алгоритмы Яндекс VQE (Voice Quality Enhancement: активное эхоподавление, очистка от фонового шума, бимформинг) и передаётся по Wi-Fi на ПК.
2. **Алиса продолжает работать в обычном режиме**: вы можете общаться с ней, слушать музыку или управлять умным домом — перехват аудиопотока не блокирует и не выключает голосовой ассистент.
3. **Интегрируется в Windows как настоящий микрофон**: через виртуальный кабель (VB-Audio Cable) звук передаётся в систему — Discord, Telegram, CS2, Dota 2, OBS видят Станцию как стандартный микрофон.
4. **Управление прямо из красивого TUI**: удобный терминальный интерфейс на Go (BubbleTea) позволяет настраивать громкость, автогейн (АРУ), задержку буфера, устанавливать или удалять патч с колонки по SSH в один клик.

### Подробности реализации:

1. **Перехват VQE без вмешательства в ALSA**:
   - На колонке работает демон `maind` (голосовая платформа Quasar).
   - Вместо попыток захватить ALSA-устройство напрямую (что сломало бы распознавание Алисы), используется библиотека-шим `libvqe_tap.so` (размером всего ~3.5 КБ).
   - Библиотека подгружается через `LD_PRELOAD` в `/system/vendor/quasar/launch.json` и перехватывает экспорт функции `YandexVqeC_GetOutputChannelData`.
   - Из неё читается готовый, уже очищенный от шума комнаты и эха музыки канал `vqe_0` (16 кГц, моно).

2. **Передача по UDP**:
   - Аудио конвертируется из float32 в PCM 16-бит (s16le).
   - Пакетами по 160 сэмплов (ровно 10 миллисекунд аудио) датаграммы мгновенно отправляются по протоколу UDP на IP-адрес вашего компьютера.
   - Минимальный оверхед: нет рукопожатий и задержек TCP, дропы сетевых пакетов не накапливают буфер.

3. **Обработка на стороне ПК (`AlisaMic.exe`)**:
   - Приложение на Go слушает UDP-порт (по умолчанию `5000`).
   - Динамический настраиваемый буфер (120–1000 мс) нивелирует джиттер Wi-Fi.
   - Встроенный цифровой АРУ (AGC / Auto Gain Control) выравнивает тихий шёпот и нормальную речь без перегрузок.
   - Поток выводится через Windows WASAPI в устройство `CABLE Input`.

4. **SSH-интеграция**:
   - Программа умеет сама подключаться к Станции по SSH (`Dropbear`), проверять статус, устанавливать/обновлять `libvqe_tap.so`, менять настройки в `launch.json`, изменять порт и пароль SSH.
   - Используется гибридный механизм: встроенный SSH-клиент с бесшовным откатом на системный `OpenSSH` для максимальной совместимости.

5. **Автоматический бэкап и безопасное удаление**:
   - Перед любыми изменениями конфигурации Станции автоматически создаётся резервная копия оригинального файла `launch.json` (сохраняется на самой колонке и дублируется на ПК).
   - При выборе пункта «Удалить скрипт с колонки» программа полностью возвращает `launch.json` из бэкапа в исходный вид и удаляет библиотеку `libvqe_tap.so` — Станция возвращается в заводское состояние.
   - Настройки ПК (`alisa-mic.json`) также сохраняются атомарно с автоматическим созданием резервной копии `.bak`.

## 📋 Системные требования

- **Яндекс Станция**: Станция Лайт 1 (Micro) с полученным root-доступом и запущенным SSH (подробнее: [hackalice.me](https://hackalice.me)).
- **Компьютер**: Windows 10 или Windows 11 (64-бит).
- **Локальная сеть**: ПК и колонка должны быть подключены к одному роутеру / подсети.
- **Драйвер виртуального аудиокабеля**: [VB-Audio Cable](https://vb-audio.com/Cable/) (бесплатный).

## 🚀 Быстрый старт

### Шаг 1. Установка VB-Audio Cable на ПК
1. Скачайте [VB-CABLE Driver Pack](https://vb-audio.com/Cable/).
2. Распакуйте архив, нажмите правой кнопкой на `VBCABLE_Setup_x64.exe` → **Запуск от имени администратора** → нажмите **Install Driver**.
3. Перезагрузка обычно не требуется.

### Шаг 2. Запуск AlisaMic
1. Скачайте свежий релиз `AlisaMic.exe` из раздела [Releases](https://github.com/awa1tt/AlisaMic/releases).
2. Запустите `AlisaMic.exe`.
3. При первом запуске появится дисклеймер (отказ от ответственности). Нажмите клавишу **Y** для подтверждения.

### Шаг 3. Подключение к колонке
1. В главном меню перейдите стрелками в пункт **Колонка (SSH)…** и нажмите **Enter**.
2. Укажите параметры подключения:
   - **IP колонки**: например `192.168.3.37`
   - **Порт SSH**: `2222`
   - **Пользователь**: `root`
   - **Пароль**: ваш root-пароль (на многих рутованных станциях по умолчанию `1`)
3. Выберите **Проверить колонку** — программа проверит доступность и состояние.
4. Нажмите **Установить / обновить** — файлы автоматически загрузятся на Станцию, а конфиг обновится.
5. Выберите **Перезагрузить колонку** (или перезагрузите её по питанию).

### Шаг 4. Включение трансляции
1. В главном меню выберите:
   - **Вывод**: `CABLE Input (VB-Audio Virtual Cable)`
   - **Трансляция**: `[ВКЛ]`
2. В Discord, Telegram, игре или настройках звука Windows выберите входное устройство (микрофон):  
   👉 **«CABLE Output (VB-Audio Virtual Cable)»**.

## ⌨️ Управление в программе

| Клавиша | Действие |
| :--- | :--- |
| `↑` / `↓` | Перемещение по меню |
| `←` / `→` | Изменение числовых значений и переключателей |
| `Enter` | Выбрать пункт / открыть подменю / подтвердить |
| `R` | Обновить статус / список устройств |
| `Esc` | Назад в предыдущее меню |
| `Q` | Выход из программы |
| `Y` / `N` | Ответ «Да» / «Нет» в диалоговых окнах |

### Пункты меню:
- **Трансляция**: включение/выключение приёма аудио.
- **Вывод**: выбор устройства (VB-Cable или колонки ПК для прямого мониторинга).
- **Автогейн**: умная нормализация громкости (АРУ).
- **Предел усиления**: максимальный коэффициент усиления (по умолчанию ×80).
- **Порт UDP**: порт приёма (по умолчанию `5000`).
- **Буфер**: размер буфера в миллисекундах (меньше = ниже задержка, больше = выше стабильность при слабом Wi-Fi).
- **Автозапуск**: автоматически начинать приём звука при старте `AlisaMic.exe`.
- **Проверка микрофона**: живой визуальный индикатор уровня микрофона Windows.
- **Диагностика…**: полная проверка всей цепочки (сеть, файрвол, UDP, SSH, службы, свободное место на Станции).

## 🛠 Запуск без интерфейса (Headless)

Для автозагрузки или ярлыков поддерживается фоновый запуск:

```powershell
AlisaMic.exe --headless --out CABLE --gain 40 --buffer 160
```

Флаги:
- `--headless` — запуск без TUI-меню.
- `--out <имя>` — устройство вывода (например, `CABLE`).
- `--gain <число>` — предел усиления.
- `--buffer <мс>` — размер буфера в миллисекундах.
- `--port <порт>` — UDP-порт.
- `--no-agc` — отключить автоматическую регулировку громкости.
