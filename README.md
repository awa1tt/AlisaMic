<h1 align="center">AlisaMic</h1>

<p align="center">Яндекс Станция Лайт как беспроводной микрофон для ПК: Discord, игры, звонки.</p>

<p align="center"><b>⚠ ПРОВЕРЕНО ТОЛЬКО НА Яндекс Станции Лайт 1</b></p>

---

> ## ⚠ DANGER — отказ от ответственности
>
> Программа **изменяет системные файлы колонки** (получает root по SSH, правит `launch.json`, может менять порт и пароль SSH, перезагружать устройство). Это неофициальная модификация.
>
> - Вы используете всё **на свой страх и риск**. Автор не отвечает за «окирпичивание» колонки, потерю данных, потерю гарантии, блокировку аккаунта, сбои сети и любой другой ущерб.
> - Программа предоставляется «как есть», без гарантий. Работа проверена **только на Яндекс Станции Лайт 1**; на других устройствах и прошивках результат непредсказуем.
> - Не нажимайте «Установить», «Сменить порт», «Сменить пароль», если не понимаете, что это делает. Перед изменениями программа делает резервные копии `*.bak-alisamic` и откатывается при ошибке, но это **не** гарантия.
> - Смена SSH‑порта и пароля может отрезать вас от колонки. Запомните новые значения; запасной вход — ADB.
> - Тот же текст показывается при первом запуске; без согласия (Y) программа не работает.

Звук берётся **после штатной обработки VQE** — шумоподавление, эхоподавление и бимформинг уже сделаны самой колонкой. Канал `vqe_0` (16 кГц, моно) уходит по Wi‑Fi на ПК с задержкой ~100–200 мс.

**Алиса при этом продолжает работать как обычно** — ничего не отключается и не блокируется.

```
[Станция]  vqe_0 ──UDP──▶  [ПК] AlisaMic.exe ──▶ CABLE Input  ⇒  Discord видит микрофон «CABLE Output»
```

## Возможности

- консольное меню: всё включается и настраивается стрелками, без правки батников;
- **экран «Колонка (SSH)»**: поля IP, SSH‑порт (по умолчанию 2222), логин (root), пароль; кнопки «Проверить колонку», «Установить / обновить», «Удалить»;
- **проверка, установлен ли скрипт на Алисе**: версия `libvqe_tap.so`, запись в `launch.json`, адрес приёмника, совпадение с IP этого ПК;
- установка и удаление прямо из программы — без `scp`/`ssh` вручную (файлы вшиты в `AlisaMic.exe`);
- **диагностика** («Диагностика…»): порт UDP, брандмауэр Windows, VB‑Cable, устройство вывода, SSH, права, прошивка/VQE, скрипт, адрес приёмника, загрузка в `maind`, rootfs, место на `/data`, приход пакетов от колонки, уровень сигнала. К найденным проблемам — кнопка исправления;
- **настройки колонки**: смена SSH‑порта и пароля (с проверкой нового входа и автооткатом), направить звук на этот ПК, перезагрузка, информация о колонке, логи, «забыть ключ хоста»;
- проверка ключа хоста SSH при первом подключении (TOFU, `alisa-mic-hosts.json`);
- выбор устройства вывода — VB‑Cable или обычные колонки;
- автогейн (АРУ): тихая речь вытягивается, тишина не усиливается;
- живые индикаторы уровня, статистика пакетов и задержки;
- встроенная проверка микрофона — уровень любого устройства записи, например «CABLE Output»;
- автозапуск трансляции и сохранение настроек в `alisa-mic.json`;
- горячие клавиши работают и на русской раскладке;
- режим без меню (`--headless`) для ярлыков и автозагрузки.

## Требования

- **Яндекс Станция Лайт 1** с root/SSH — см. [hackalice.me](https://hackalice.me). На других станциях не проверялось.
- ПК с Windows 10/11 в той же сети.
- [VB‑Cable](https://vb-audio.com/Cable/) — если нужен именно микрофон в Discord/играх. Для прослушивания через колонки не нужен.

## Установка

### 1. ПК

1. Установите VB‑Cable (`VBCABLE_Setup_x64.exe` от администратора → Install Driver).
2. Запустите `AlisaMic.exe`, прочитайте отказ от ответственности и нажмите **Y**.

### 2. Колонка — из программы

1. **Колонка (SSH)…** → введите IP колонки, SSH‑порт, логин и пароль (пример: `192.168.3.37`, `2222`, `root`).
2. **Проверить колонку** — программа покажет, установлен ли скрипт.
3. **Установить / обновить** — файлы загружаются на колонку, в `launch.json` добавляются `LD_PRELOAD` и `ALICE_TAP_TARGET=<IP ПК>:5000` (перед этим создаётся копия `launch.json.bak-alisamic`).
4. **Перезагрузите колонку** (пункт в «Настройки колонки» или вручную) — после этого микрофон стримится автоматически.
5. В главном меню: **Вывод** → `CABLE Input`, **Трансляция** → включить.
6. В Discord/игре выберите микрофон **«CABLE Output (VB‑Audio Virtual Cable)»**.

Если что-то не работает — **Диагностика…** покажет причину и предложит исправление.

Пароль сохраняется в `alisa-mic.json` **открытым текстом только если включено «Запомнить пароль»**. Пароль `1`, стоящий на многих рутованных колонках, лучше сменить в «Настройки колонки».

<details>
<summary>Ручная установка (без программы)</summary>

Скопируйте папку `station/` на колонку и запустите установщик, указав **IP вашего ПК**:

```sh
scp -P 2222 station/* root@192.168.3.37:/tmp/
ssh -p 2222 root@192.168.3.37
cd /tmp && sh install.sh 192.168.3.5
reboot
```
</details>

<details>
<summary>Откат</summary>

Из программы: **Колонка (SSH)…** → **Удалить**. Вручную:

```sh
ssh -p 2222 root@<ip_колонки>
mount -o remount,rw / && cp /system/vendor/quasar/launch.json.bak-alisamic /system/vendor/quasar/launch.json && mount -o remount,ro / && reboot
```

Если SSH недоступен после смены порта/пароля — зайдите через ADB и верните файлы из `*.bak-alisamic`.
</details>

## Управление

| Клавиша | Действие |
| --- | --- |
| `↑` `↓` | выбор пункта |
| `←` `→` | изменить значение |
| `Enter` | включить / выключить, открыть экран, редактировать поле |
| `Y` / `N` | подтверждения и отказ от ответственности |
| `R` | обновить список устройств / статус |
| `Esc` | назад |
| `Q` | выход (если идёт трансляция — спросит подтверждение) |

Пункты главного меню: Трансляция, Вывод, Автогейн, Предел усиления, Порт UDP, Буфер, Автозапуск, Проверка микрофона, **Колонка (SSH)…**, **Диагностика…**, **Отказ от ответственности**.

| Пункт | Что делает |
| --- | --- |
| Трансляция | приём звука с колонки |
| Вывод | куда идёт звук: `CABLE Input` или колонки |
| Автогейн | автоматическая громкость |
| Предел усиления | максимум автогейна (по умолчанию ×80); при выключенном автогейне — постоянное усиление |
| Порт UDP | должен совпадать с портом на колонке (по умолчанию 5000) |
| Буфер | меньше — ниже задержка, больше — стабильнее по Wi‑Fi |
| Автозапуск | включать трансляцию сразу при запуске |
| Проверка микрофона | живой уровень устройства записи |

### Без меню

```
AlisaMic.exe --headless --out CABLE --gain 40
```

Флаги: `--out <часть имени>` (`-` — колонки по умолчанию), `--gain`, `--port`, `--buffer <мс>`, `--no-agc`.

## Файлы настроек

- `alisa-mic.json` — настройки (рядом с exe или в `%APPDATA%\AlisaMic`);
- `alisa-mic-hosts.json` — доверенные ключи хостов SSH.

## Совместимость

Проверено только на Яндекс Станции Лайт 1. Скрипт установки сам проверяет наличие символа VQE и откажется ставиться, если он не найден; вручную:

```sh
grep -c YandexVqeC_GetOutputChannelData /system/vendor/quasar/libs/libyandex_evil.so
```

`1` — подходит, `0` — эта прошивка не поддерживается. На станциях с 64‑битным userspace готовый `libvqe_tap.so` (32‑бит armhf) не загрузится — пересоберите его.

## Сборка

**ПК** — Go 1.23+:

```
cd pc
build.bat
```

`build.bat` копирует `station\libvqe_tap.so` и `station\install.sh` в `pc\embed` (остальные скрипты лежат там же) и вшивает их в exe.

**Шим для колонки** — [Zig](https://ziglang.org/download/) (armhf, glibc 2.30):

```sh
zig build-lib -O ReleaseSmall -dynamic -target arm-linux-gnueabihf.2.30 -fstrip -lc -ldl --name vqe_tap station/vqe_tap_udp.c
```

## Как это устроено

В голосовой движок (`maind --platformd`) через `LD_PRELOAD` подгружается шим `libvqe_tap.so` (3.5 КБ). Он перехватывает `YandexVqeC_GetOutputChannelData` из `libyandex_evil.so`, забирает обработанный канал `vqe_0` (float32 → s16le) и шлёт UDP‑датаграммы по 10 мс на ПК. ALSA напрямую не трогается — микрофон остаётся у штатного демона.

AlisaMic на ПК собирает пакеты в блоки по 40 мс, применяет АРУ и отдаёт их в `waveOut` выбранного устройства.

## Нюансы

- Аппаратный мьют микрофона на колонке — звука не будет.
- VQE приглушает постоянный фон и звук из динамика самой колонки — это фича.
- Обновление прошивки может стереть патч `launch.json` — проверьте колонку в программе и переустановите.
